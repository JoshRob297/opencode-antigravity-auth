# Security Policy

## Supported Versions

Only the latest release is actively supported with security patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.7.x   | :white_check_mark: |
| < 1.7.0 | :x:                |

## Reporting a Vulnerability

We take the security and privacy of our users very seriously. If you believe you have found a security vulnerability in this project, please **do not open a public issue**.

Instead, please report security vulnerabilities responsibly:

1. **GitHub Security Advisory**: Use GitHub's private vulnerability reporting feature under the **Security** tab of this repository.
2. **Direct Contact**: If private reporting is unavailable, reach out directly to the maintainer via GitHub profile [@JoshRob297](https://github.com/JoshRob297).

### Information to Include

Please provide the following details to help us triage and fix the issue promptly:
- Type of issue (e.g., token leakage, command injection, authorization bypass)
- Step-by-step reproduction instructions or a minimal proof of concept (PoC)
- Potential impact and affected components/platforms (macOS, Linux, Windows, WSL)
- Any proposed mitigations or patches

### Responsible Disclosure & Timeline

- We will acknowledge receipt of your vulnerability report within **48 hours**.
- We will provide a timeline for triage and remediation.
- Once a fix is released, we will publish an advisory acknowledging your contribution (unless you prefer to remain anonymous).
